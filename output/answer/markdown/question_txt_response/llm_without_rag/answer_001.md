# Question
คนไทยเชื้อสายจีนในหาดใหญ่ มีสัดส่วนของคนเชื้อสายจีนในแต่ละสายเป็นอย่างไร (กวางตุ้ง, ฮกเกี้ยน, แต้จิ๋ว, ฮากกา / แคะ, ยูนนาน, อื่นๆ)


# Answer

## Typhoon
ข้อมูลเกี่ยวกับสัดส่วนของคนไทยเชื้อสายจีนใน **หาดใหญ่** โดยเฉพาะในด้าน **เชื้อสายจีน** ที่แบ่งตามภูมิภาคของจีน (เช่น กวางตุ้ง, ฮกเกี้ยน, แต้จิ๋ว, ฮากกา/แคะ, ยูนนาน, อื่นๆ) ยังไม่มีการสำรวจอย่างเป็นทางการที่ชัดเจนในระดับท้องถิ่นหรือระดับจังหวัด แต่สามารถวิเคราะห์จากข้อมูลทางประวัติศาสตร์ วัฒนธรรม และการตั้งถิ่นฐานของชุมชนจีนในภาคใต้ของประเทศไทย โดยเฉพาะใน **จังหวัดสงขลา** ซึ่งมี **หาดใหญ่** เป็นศูนย์กลางทางเศรษฐกิจและวัฒนธรรม

### 1. **ลักษณะการตั้งถิ่นฐานของชาวจีนในหาดใหญ่**
- ชุมชนจีนในหาดใหญ่ส่วนใหญ่เริ่มต้นจากการอพยพของชาวจีนในช่วง **ศตวรรษที่ 19–20** โดยเฉพาะในช่วง **การเปิดเส้นทางการค้าทางทะเล** และ **การพัฒนาการเกษตรและอุตสาหกรรมในภาคใต้**
- ชาวจีนที่อพยพมายังหาดใหญ่ส่วนใหญ่มาจาก **มณฑลกวางตุ้ง (Guangdong)**, **มณฑลฮกเกี้ยน (Fujian)**, และ **มณฑลแต้จิ๋ว (Hainan)** ซึ่งเป็นพื้นที่ที่มีการอพยพมากที่สุดในช่วงแรก

### 2. **สัดส่วนเชื้อสายจีนในหาดใหญ่ (โดยประมาณ)**

| เชื้อสายจีน | ประมาณสัดส่วน | หมายเหตุ |
|-----------|----------------|---------|
| **กวางตุ้ง (Cantonese)** | ประมาณ 40–50% | กลุ่มใหญ่ที่สุด ตั้งถิ่นฐานตั้งแต่ช่วงต้นศตวรรษที่ 20 ผ่านการค้าและแรงงานในภาคใต้ |
| **ฮกเกี้ยน (Hokkien)** | ประมาณ 25–30% | กลุ่มที่มีบทบาททางเศรษฐกิจและวัฒนธรรม ตั้งแต่ช่วงการตั้งถิ่นฐานในช่วงสงครามโลกครั้งที่ 1–2 |
| **แต้จิ๋ว (Hainanese)** | ประมาณ 10–15% | กลุ่มที่มีความหลากหลายทางวัฒนธรรม แต่ส่วนใหญ่ตั้งถิ่นฐานในพื้นที่ทางใต้ของจังหวัดสงขลา |
| **ฮากกา/แคะ (Hakka)** | ประมาณ 5–10% | กลุ่มที่มีความเข้มแข็งในด้านการเกษตรและธุรกิจขนาดเล็ก |
| **ยูนนาน (Yunnanese)** | ประมาณ 5% หรือน้อยกว่า | กลุ่มที่มีจำนวนน้อย แต่มีความหลากหลายทางวัฒนธรรม |
| **อื่นๆ (เช่น จีนกลาง, จีนไต้หวัน, จีนฮ่องกง, จีนสิงคโปร์)** | ประมาณ 5–10% | กลุ่มที่อพยพในช่วงหลัง หรือมีการแต่งงานข้ามเชื้อสาย |

> **หมายเหตุ**: ข้อมูลนี้เป็นการประมาณการจากลักษณะทางวัฒนธรรม ภาษา ชื่อสกุล และการสืบเชื้อสาย ไม่ใช่ข้อมูลทางสถิติอย่างเป็นทางการจากสำนักงานสถิติแห่งชาติ

### 3. **ปัจจัยที่ส่งผลต่อสัดส่วนเชื้อสายจีนในหาดใหญ่**
- **การค้าและการอพยพทางเศรษฐกิจ**: ชาวจีนกวางตุ้งมีบทบาทสำคัญในด้านการค้า ซึ่งส่งผลให้กลุ่มนี้มีจำนวนมากที่สุด
- **การตั้งถิ่นฐานในช่วงสงครามโลกครั้งที่ 2**: ชาวจีนฮกเกี้ยนและแต้จิ๋วมีการอพยพเข้ามาในช่วงสงคราม ทำให้เกิดชุมชนที่มีความเข้มแข็ง
- **การแต่งงานข้ามเชื้อสาย**: ปัจจุบันมีการผสมผสานทางเชื้อสายมากขึ้น ทำให้สัดส่วนเชื้อสายจีนในรุ่นหลังมีความหลากหลาย

## KBTG
ข้อมูลเกี่ยวกับสัดส่วนของคนไทยเชื้อสายจีนในหาดใหญ่ โดยเฉพาะกลุ่มเชื้อสายจีนแต่ละภูมิภาค (กวางตุ้ง, ฮกเกี้ยน, แต้จิ๋ว, ฮากกา, แคะ, ยูนนาน, อื่นๆ) อาจไม่ได้ถูกจัดเก็บอย่างเป็นทางการในระดับท้องถิ่น แต่สามารถวิเคราะห์จากข้อมูลทั่วไปเกี่ยวกับการอพยพของชาวจีนไปยังประเทศไทย และบทบาทของแต่ละกลุ่มในหาดใหญ่ได้ดังนี้:

### 1. **ชาวจีนเชื้อสายกวางตุ้ง (Guangdong)**
   - **สัดส่วน**: ประมาณ **60-70%** ของประชากรเชื้อสายจีนในหาดใหญ่
   - **เหตุผล**: ชาวจีนจากกวางตุ้งเป็นกลุ่มที่อพยพไปยังประเทศไทยมากที่สุดในช่วงศตวรรษที่ 19-20 โดยเฉพาะในภาคใต้ ซึ่งเป็นแหล่งผลิตยางพาราและแร่ธาตุ ชาวกวางตุ้งมีบทบาทสำคัญในธุรกิจการค้าและการลงทุนในหาดใหญ่
   - **ลักษณะ**: รักษาวัฒนธรรมและภาษาจีนกลาง (Mandarin) มากกว่ากลุ่มอื่น

### 2. **ชาวจีนเชื้อสายฮกเกี้ยน (Fujian)**
   - **สัดส่วน**: ประมาณ **15-20%**
   - **เหตุผล**: ชาวฮกเกี้ยนอพยพไปยังไทยในช่วงเวลาเดียวกันกับชาวกวางตุ้ง แต่ส่วนใหญ่ตั้งถิ่นฐานในพื้นที่อื่น เช่น ชลบุรี ภูเก็ต แต่ก็มีจำนวนไม่น้อยในหาดใหญ่
   - **ลักษณะ**: รักษาภาษาฮกเกี้ยน (Hokkien) และมีวัฒนธรรมที่เน้นความเป็นครอบครัว

### 3. **ชาวจีนเชื้อสายแต้จิ๋ว (Teochew)**
   - **สัดส่วน**: ประมาณ **5-10%**
   - **เหตุผล**: ชาวแต้จิ๋วมีจำนวนน้อยกว่ากลุ่มอื่น แต่ก็มีบทบาทในธุรกิจและชุมชน บางส่วนอาจมีความสัมพันธ์กับชาวจีนในจังหวัดสงขลา
   - **ลักษณะ**: รักษาภาษาแต้จิ๋ว (Teochew) และมีวัฒนธรรมที่เน้นความเป็นมิตร

### 4. **ชาวจีนเชื้อสายฮากกา (Hakka)**
   - **สัดส่วน**: ประมาณ **5-10%**
   - **เหตุผล**: ชาวฮากกาอพยพไปยังไทยในช่วงเวลาที่แตกต่างกัน แต่ส่วนใหญ่ตั้งถิ่นฐานในพื้นที่อื่น เช่น ชลบุรี แต่ก็มีจำนวนไม่น้อยในหาดใหญ่
   - **ลักษณะ**: รักษาภาษาฮากกา (Hakka) และมีวัฒนธรรมที่เน้นความอดทนและทำงานหนัก

### 5. **ชาวจีนเชื้อสายแคะ (Hainan)**
   - **สัดส่วน**: ประมาณ **5%**
   - **เหตุผล**: ชาวแคะมีจำนวนน้อยในประเทศไทย แต่บางส่วนอาจมีความสัมพันธ์กับชาวจีนในจังหวัดสงขลา
   - **ลักษณะ**: รักษาภาษาแคะ (Hainanese) และมีวัฒนธรรมที่เน้นความเป็นมิตร

### 6. **ชาวจีนเชื้อสายอื่นๆ**
   - **สัดส่วน**: ประมาณ **5-10%**
   - **เหตุผล**: รวมถึงชาวจีนจากยูนนาน, ซานตง, ชานตง, และกลุ่มอื่นๆ ที่อพยพมาในช่วงเวลาต่างกัน
   - **ลักษณะ**: รักษาภาษาและวัฒนธรรมเฉพาะของแต่ละกลุ่ม

### ข้อสังเกต:
- **ข้อมูลไม่แน่นอน**: ข้อมูลเกี่ยวกับสัดส่วนเชื้อสายจีนในหาดใหญ่อาจไม่ได้ถูกจัดเก็บอย่างเป็นทางการ ดังนั้นตัวเลขอาจมีความคลาดเคลื่อน
- **วัฒนธรรมผสมผสาน**: ชาวจีนในหาดใหญ่มักมีการผสมผสานวัฒนธรรมไทยและจีน ทำให้การแยกกลุ่มเชื้อสายอาจไม่ชัดเจน
- **บทบาทในชุมชน**: กลุ่มกวางตุ้งมีบทบาทสำคัญในธุรกิจและเศรษฐกิจของหาดใหญ่ ขณะที่กลุ่มอื่นๆ มีบทบาทในด้านวัฒนธรรมและชุมชน

หากต้องการข้อมูลที่แม่นยำมากขึ้น อาจต้องพึ่งพาการสำรวจหรืองานวิจัยเฉพาะท้องถิ่น ซึ่งอาจไม่ได้เผยแพร่ในวงกว้างในขณะนี้

## Pathumma
คนไทยเชื้อสายจีนในหาดใหญ่ มีสัดส่วนของกลุ่มเชื้อสายจีนหลักๆ ดังนี้ (ข้อมูลโดยประมาณ ไม่ใช่ตัวเลขทางการ):

1. **แต้จิ๋ว (Teochew)**  
   - เป็นกลุ่มใหญ่ที่สุดในหาดใหญ่ คาดว่ามีสัดส่วนประมาณ **40-50%**  
   - แต้จิ๋วเป็นกลุ่มที่อพยพเข้ามาตั้งแต่สมัยรัชกาลที่ 5-6 ตั้งถิ่นฐานในย่านตลาดเก่าและชุมชนรอบนอก  
   - มีวัฒนธรรมโดดเด่น เช่น อาหารแต้จิ๋ว (เช่น หมี่ฮกเกี้ยน) และภาษาแต้จิ๋ว  

2. **กวางตุ้ง (Cantonese)**  
   - รองลงมา คาดว่ามีสัดส่วนประมาณ **25-30%**  
   - กลุ่มนี้มักตั้งถิ่นฐานในย่านการค้าและธุรกิจ เช่น ถนนนิพัทธ์อุทิศ 1-3  
   - ภาษาและวัฒนธรรมกวางตุ้งมีอิทธิพลต่ออาหารและประเพณีในพื้นที่  

3. **ฮากกา (Hakka)**  
   - มีสัดส่วนประมาณ **15-20%**  
   - ฮากกาเป็นกลุ่มที่มีเอกลักษณ์เฉพาะ เช่น ภาษาฮากกาและวัฒนธรรมการแต่งกาย  
   - มักตั้งถิ่นฐานในพื้นที่ภูเขาหรือชุมชนที่มีความหลากหลายทางชาติพันธุ์  

4. **ยูนนาน (Yunnanese)**  
   - เป็นกลุ่มเล็ก คาดว่ามีสัดส่วนประมาณ **5-10%**  
   - กลุ่มนี้มักตั้งถิ่นฐานในพื้นที่ห่างไกลหรือชุมชนที่มีการอพยพในช่วงสงคราม  

5. **อื่นๆ (รวมฮกเกี้ยน, แคะ, ไหหลำ, ฯลฯ)**  
   - กลุ่มเล็กๆ ที่มีสัดส่วนรวมประมาณ **5-10%**  
   - ฮกเกี้ยน (Hokkien) อาจมีสัดส่วนเล็กน้อย แต่ไม่โดดเด่นเท่ากลุ่มหลัก  

**หมายเหตุ:**  
- สัดส่วนนี้เป็นการประมาณการจากข้อมูลทางประวัติศาสตร์และวัฒนธรรม ไม่มีสถิติทางการ  
- กลุ่มแต้จิ๋วและกวางตุ้งมักถูกกล่าวถึงร่วมกันในบริบทของ "จีนทางใต้" แต่แยกย่อยตามภูมิภาค  
- ความหลากหลายทางชาติพันธุ์ในหาดใหญ่สะท้อนประวัติศาสตร์การอพยพของจีนในภาคใต้ของไทย
